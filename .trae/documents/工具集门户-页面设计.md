# 工具集门户 - 页面设计（Desktop-first）

## 全局设计规范
- Layout：桌面端优先（内容容器 max-width 1200px，左右留白）；内部使用 CSS Grid（卡片区/双栏区）+ Flex（行内对齐）。
- Breakpoints：≥1200px（3-4 列卡片），768-1199px（2 列），<768px（1 列堆叠；控制台区改为上下布局）。
- Global Styles（Tokens）
  - 背景：#0B1220（深色） / 内容卡片：#111B2E
  - 主色：#4F8CFF；强调：#22C55E；警告：#F59E0B；错误：#EF4444
  - 字体：系统字体栈；字号：12/14/16/20/24/32
  - Button：Primary（主色填充）、Secondary（描边）、Danger（红色）；hover 提升亮度+阴影
  - Link：主色下划线 hover；Code：等宽字体，背景 #0F172A
- 顶部导航（全站一致）
  - 左：Logo + 产品名“工具集门户”
  - 中：导航（首页 / 浏览 / 演示 / 部署监控）
  - 右：环境选择（默认/自定义 Base URL）+ 文档/仓库链接（如有）

## Page 1：首页（能力展示）
- Meta
  - title：工具集门户｜能力展示
  - description：集中展示工具集能力，快速进入 API 浏览与调用演示。
  - og:title/og:description 同上
- Page Structure：纵向堆叠分区（Hero → 能力卡片 → 场景/流程 → 快速开始）
- Sections & Components
  1. Hero 区（两栏）
     - 左：标题（H1）+ 2 行简介 + 主要 CTA「开始浏览」/ 次要 CTA「打开演示」
     - 右：插画/示意图占位（可后续替换）
  2. 能力概览卡片区（Grid）
     - 卡片字段：能力名、简介、标签、入口按钮（跳转到对应工具分类或演示）
  3. 典型使用路径（横向步骤条）
     - Step1 选工具 → Step2 看参数 → Step3 发起调用 → Step4 复制代码
  4. 快速开始（可复制代码块）
     - 展示最短示例：选择工具下拉 + 一键跳转到对应 Playground（带默认示例参数）

## Page 2：工具/API 浏览页
- Meta
  - title：工具/API 浏览｜工具集门户
  - description：按分类、标签与关键字浏览工具与 API。
- Layout：左侧筛选栏（固定宽 280px）+ 右侧列表（自适应）；小屏折叠筛选为抽屉。
- Sections & Components
  1. 筛选栏
     - 分类树/分组
     - 标签多选
     - 关键字搜索框（回车触发/防抖）
  2. 工具列表（卡片列表或表格）
     - 行/卡片：名称、简介、方法/类型标识、标签、最近更新（如有静态信息）
     - 点击进入工具详情（/tools/:toolId）

### 子页面：工具详情（/tools/:toolId）
- Page Structure：顶部摘要 + 下方 Tab（说明 / 参数 / 返回 / 示例）
- 关键组件
  - 摘要区：工具名、短描述、Endpoint、支持的方法（GET/POST 等）
  - 参数表：字段名、类型、是否必填、说明
  - 返回表：字段名、类型、说明
  - 示例区：示例请求/响应（可复制）+ CTA「去演示」跳 /playground/:toolId

## Page 3：调用演示页（交互控制台）
- Meta
  - title：调用演示｜工具集门户
  - description：交互式构造请求并查看结果、日志与可复制代码。
- Layout：桌面端双栏（左：请求构造；右：响应/日志）；小屏上下堆叠。
- Sections & Components
  1. 顶部工具摘要条
     - 显示 tool 名、Endpoint、当前环境 Base URL
     - 操作：重置参数、载入示例、复制链接（带 toolId）
  2. 左栏：请求构造
     - 参数模式切换：Form / JSON
     - Form 模式：基于参数定义渲染输入控件（text/number/select/switch）
     - JSON 模式：代码编辑器（支持格式化、基础校验）
     - 发送按钮：展示 loading、禁用重复提交
  3. 右栏：响应与日志
     - 状态概览：HTTP 状态码、耗时、时间戳
     - Tabs：Response Body / Headers / Logs
     - 错误态：错误原因、重试按钮
     - 代码片段：cURL / fetch（可复制）

---

## Page 4：部署与监控入口页
- Meta
  - title：部署与监控｜工具集门户
  - description：提供部署与监控的统一入口与环境信息。
- Page Structure：信息卡片 + 入口卡片网格
- Sections & Components
  1. 环境信息卡
     - 环境名称（如 Dev/Prod）、版本号/构建号（如可用则展示）、健康提示（静态/占位均可）
  2. 部署入口区（卡片 Grid）
     - 入口卡：名称、说明、跳转按钮（外链打开，新窗口）
  3. 监控入口区（卡片 Grid）
     - 日志 / 指标 / 链路 / 告警入口（均为链接形态，便于对接现有平台）
